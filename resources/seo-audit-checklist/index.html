The Master Website SEO Audit Checklist (2026 Edition)

An actionable, step-by-step technical and on-page SEO framework used by agency consultants to systematically audit any prospective client domain and diagnose ranking issues.

Phase 1: Technical Crawling & Indexability

  • ✓
    Robots.txt Configuration: Verify User-agent directives allow key assets and reference the root sitemap_index.xml. Ensure staging environments or sensitive routes (/api/, /auth/) are disallowed.
  • ✓
    Multi-Sitemap Index Structure: Ensure separate sitemaps exist for core pages, tools, blog posts, and resources. Verify strict ISO 8601 timestamps (<lastmod>) and remove deprecated priority/changefreq tags.
  • ✓
    Canonical URL Tags: Ensure every page includes a self-referential canonical tag with matching protocol (https://) and preferred domain variation (apex vs www).
  • ✓
    Canonical 301 Redirect Rules: Confirm all non-canonical permutations (http://, www., trailing slash variations) issue permanent 301 redirects to the primary domain.
  • ✓
    HSTS & Security Headers: Confirm Strict-Transport-Security: max-age=63072000; includeSubDomains; preload is transmitted alongside valid SSL encryption.

Phase 2: On-Page Semantic Hierarchy & Content

  • ✓
    Single H1 Heading Tag: Verify exactly one H1 exists per page that includes the primary target keyword without keyword stuffing.
  • ✓
    Semantic Heading Hierarchy: Audit H2, H3, and H4 tags to ensure a logical document outline without skipped heading levels (e.g. jumping from H2 directly to H4).
  • ✓
    Title Tag Pixel Length: Keep page titles between 50-60 characters (under 580 pixels) to avoid awkward SERP truncation while positioning core brand and keywords upfront.
  • ✓
    Compelling Meta Descriptions: Ensure meta descriptions are under 155 characters and feature an active call-to-action to optimize click-through rate (CTR).
  • ✓
    Image Alt Text & Dimensions: Verify every content image includes descriptive alt text, and explicit width/height attributes to eliminate Cumulative Layout Shift (CLS).

Phase 3: Core Web Vitals & Speed Performance

  • ✓
    Largest Contentful Paint (LCP): Ensure the primary viewport image or text block renders under 2.5 seconds. Preload hero assets using fetchpriority="high".
  • ✓
    Cumulative Layout Shift (CLS): Maintain a CLS score under 0.1 by reserving layout space for web fonts, responsive embeds, and hero graphics.
  • ✓
    Interaction to Next Paint (INP): Audit JavaScript execution to ensure user interactions (clicks, keypresses, taps) process within 200 milliseconds.

Phase 4: Schema.org JSON-LD Structured Entities

  • ✓
    Organization & Publisher Schema: Include official company name, logo URL, customer support contact points, and verified sameAs social profiles.
  • ✓
    Author & E-E-A-T Person Entity: Link articles and guides to dedicated author pages with verified industry expertise, employment history, and editorial credentials.
  • ✓
    BreadcrumbList Schema: Enable Google SERP breadcrumb paths to visually reinforce site SILO architecture.

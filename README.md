# AuditPilot — Public Frontend Distribution

Production build of AuditPilot for GitHub Pages and Cloudflare CDN.

## Files
- `index.html`: Optimized production single-page application.
- `404.html`: Fallback for direct URL refresh & client-side routing.
- `.nojekyll`: Instructs GitHub Pages to serve static files without Jekyll interpretation.
- `assets/`: Minified and fingerprint-hashed JS and CSS bundles.
